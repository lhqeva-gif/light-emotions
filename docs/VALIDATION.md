## bin / CIE / 人工坐标交互补充

- 有 bin 的素材默认打开灯光回放。播放器按文件标识加载，不再因标签或坐标对象更新取消请求；进度使用真实帧数/帧率，失败可重试。
- CIE 三角形按每个像素的 xy 坐标转换为 D65 sRGB，并以实测 RGB 三点裁切。显示器色域之外的颜色经过压缩/裁切，只是屏幕近似，不能代替光谱实测还原。各图使用独立裁切标识。
- 详情中的“编辑情绪坐标”支持拖动 P/A 平面和键盘操作 P/A/D 滑杆。点击“应用坐标”更新模型、情绪目标、唤醒分档和反馈校准；“恢复原始模型”撤销覆盖。人工坐标仅本次会话有效，不改写 bin/实测数据/原始反馈。已有反馈时，生效 A 仍按既有反馈权重融合，因此不一定等于人工输入的模型 A。
- 新增 CIE 转换和人工坐标回归测试，数据测试共 14 项。`tests/media-browser.mjs` 覆盖七份 bin 自动播放/暂停、滑杆与拖动应用/恢复、CIE 图像、手机宽度以及模拟加载失败后的重试。

## 已纠正的口径

- 原“指标准确率”是两个工程模型之间的吻合分数。现在明确标为启发式参考，不作为实验准确率。
- SAM 唤醒分档一致率由**未校准模型**与**每条原始反馈**逐条比较计算，无反馈显示 `—`，没有最低保底分。该指标是样本内描述，不是独立测试集准确率。
- 光通量 lm、照度 lx、LED 相对输出百分比和画面明度 L* 不混合成一个“综合亮度”，也不直接互相换算。
- 设计意图中的白光模式不再混入另一彩光模式的通量；光通量缺失时不以照度冒充。
- 后导入的 LED 数据优先，人工主/次标签保留；γ 调整会更新模型通量和平均相对输出，原始时序曲线与峰值明确标注为原始 γ。
- 严格多数为超过 50%，平票不判作多数；L2 在当前实现中只是达到 5 条反馈，不代表完成受控实验。
- 导入保留时间戳、去重，拒绝越界/非整数评分、无效日期和未知标签。会话外上传素材的反馈保留，但不计入当前素材统计。


结果：12 项数据测试通过，类型检查与构建通过。包括分类层级、九种分组计数、SAM 边界、反馈去重/回传、连续测评快照、光量与 γ 的作用、数据来源优先级，以及七份实际 `.bin` 文件重解析的帧数、时长、通量与模型结果对照。

`PLAYWRIGHT_MODULE` 可指向任意已安装 Playwright 的模块入口；未提供时使用项目环境中的 `playwright`。当前测试已通过 320、390、768、1024、1440px 宽度检查，覆盖筛选/搜索/空状态/重置、提交反馈后连续切换、LED 暂停播放、详情页签、关键数值溢出、手机反馈定位及实验室/统计/理论导航。测试使用独立浏览器上下文，不改写用户的浏览器数据。

## 边界与已知提示

- 模型系数、PAD 原型和分档属于工程假设；光通量与明度只能作为参考。心理效果与生理指标仍需受控实验及独立样本验证。
- 小样本置信区间仅作正态近似描述，单条反馈不报告区间。
- 构建仍有原有的大体积 JS 分块提示，不影响本次构建结果。
- 项目自带的 oxfmt 0.2 在无分号的行内 TypeScript 类型上删除了必要分隔符；本次已按 TypeScript 语法诊断修复，并通过类型检查。后续运行该旧格式化器后仍应执行类型检查，测试加载器也会拒绝语法错误。
